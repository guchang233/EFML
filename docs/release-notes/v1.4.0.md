EFML 1.4.0：主页运行态按钮切换为「关闭游戏」（带二次确认）及启动中状态保护。

## 改进与修复

- **游戏运行中切换为「关闭游戏」**：当检测到 `Endfield.exe` 已运行时，主页主按钮不再保持「直接启动游戏」高亮状态，自动取消高亮并切换为「关闭游戏」，同时禁用「用官方启动器启动」按钮。
- **关闭游戏二次确认与提权回退**：点击「关闭游戏」后会弹出确认对话框（默认焦点在「取消」），确认后再结束游戏进程；因游戏以管理员权限运行而管理器为普通权限，直接结束遇权限不足时会自动回退到提权 `taskkill`（支持 UAC 取消提示），游戏退出后 `EFML.Launcher.exe` 会同步清理挂起的官方启动器父进程。
- **启动中防重复点击**：点「直接启动游戏」后，在 `EFML.Launcher.exe` 正在拉起 `Endfield.exe` 的窗口期内，主按钮显示「正在启动…」并禁用，防止连续误点。

## 升级

覆盖安装即可，设置与模组保留。运行时目录更新为 `runtime\1.4.0\`。
