EFML 1.0.1：适配终末地 1.6.3 的官方启动器，**不再直接启动游戏**。

## 变化

- 「启动游戏」按钮改为：安装 / 更新加载组件（`xinput1_4.dll` 代理），然后指引你用鹰角官方启动器开始游戏。`efml launch` 同样只安装代理并显示步骤。
- 移除旧版「注入」加载方式及其设置（加载方式、游戏启动参数、启动后最小化）。终末地 1.6.3 会拒绝直接运行游戏本体，这些设置已无意义。
- 首次运行对话框、启动页、设置页的文字同步更新；README 和 [启动说明](https://github.com/guchang233/EFML/blob/main/docs/OFFICIAL-LAUNCHER.md) 重写为用户文档。
- 开发文档：游戏中用新的模块身份可以热加载，沿用同一身份需要重启游戏。

## 升级

覆盖安装即可，设置和模组保留。升级后在「启动」页点一次「启动游戏」，会把代理更新到 1.0.1。旧设置文件里的多余字段会被忽略。

## 已知限制

- 尚未经过完整的游戏内验证（宿主检查 36 项通过，管理器构建成功）。
- 不能与 Better-Endfield 在同一游戏进程中同时使用；仅支持 Windows x64。
- 使用模组可能违反游戏服务条款并导致账号受限，请自行评估风险。
