EFML 1.0.0 是第一个版本：《明日方舟：终末地》模组加载器与管理器，以 Better-Endfield 的核心组件为基础。

## 内容

- **管理器** `EFML.exe`（WinUI 3）：启动游戏，实时查看宿主、游戏线程、各模组的状态与日志；导入、启用、排序、移除模组，打开模组页面；可选择注入或 xinput 代理两种加载方式。
- **运行时**：
  - `EFML.Host.dll`：游戏内的模组宿主
  - `EFML.Injector.exe` 与 `EFML.Bootstrap.dll`：注入加载
  - `xinput1_4.dll`：代理加载
- **命令行工具** `runtime\efml.exe`：status、add、enable、disable、remove、config、send、logs、launch、proxy。
- **SDK**：头文件、示例模组 Echo 和[开发文档](https://github.com/guchang233/EFML/blob/main/docs/MODULE-API.md)。

## 兼容性

兼容 Better-Endfield 第三方模块的包格式 1 / ABI 1：为 Better Endfield 3.x 或 Next 4.x 编译的模块无需重新编译即可加载。

## 已知限制

- 已通过自动化测试和 CI 构建，**尚未经过完整的游戏内验证**。欢迎在 Issues 中反馈。
- 不能与 Better-Endfield 在同一游戏进程中同时使用。
- 仅支持 Windows x64。
- 使用模组可能违反游戏服务条款并导致账号受限，请自行评估风险。
