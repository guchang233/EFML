# 启动终末地

终末地 1.6.3 只接受从鹰角官方启动器启动，直接运行 `Endfield.exe` 会被拒绝。所以 **EFML 不启动游戏**，而是装一个 `xinput1_4.dll` 代理到游戏目录：游戏按正常 Windows DLL 加载流程载入它，代理等待 IL2CPP 就绪后加载 EFML 宿主，再加载已启用的模组。

这个流程没有使用官方模组接口，不代表官方授权。

## 步骤

1. 在 EFML「模组」页安装并启用模组。
2. 在「启动」页点击「启动游戏」。EFML 会安装或更新加载组件（代理），并弹出启动步骤。游戏正在运行时无法安装，请先关闭。
3. 打开鹰角启动器，点击「开始游戏」。
4. 回到 EFML「启动」页，进入游戏场景后，宿主、游戏线程和模组会依次变为运行中。

代理只需安装一次；之后直接从官方启动器开始游戏即可，不用每次先打开 EFML。

命令行等价：`runtime\efml.exe launch`（安装代理并显示步骤，不启动游戏），`efml proxy install|remove` 单独管理代理，`efml status` 查看状态。

## 常见情况

- **游戏目录里已有别的加载器的 `xinput1_4.dll`**：EFML 不会覆盖或删除它。请先用它自带的工具卸载，再回来。
- **升级 EFML**：「启动」页再点一次「启动游戏」，会把过期的代理更新到当前版本。
- **从 1.0.0 升级**：1.0.0 的「注入」加载方式已移除。已安装代理的无需操作；否则按上面的步骤安装一次代理即可。
- **游戏更新后模组没反应**：看「启动」页的宿主日志，帧来源或方法解析可能失效。
